4. WORKING PRINCIPLE

 sense · think · act
The working principle of this robot is based on sensing, thinking, and acting. When the robot is switched on, it starts moving forward. The ultrasonic sensor, which works like its eyes, continuously checks if there is any obstacle in front of it. This process is called continuous environmental sensing.
If the path is clear, the robot keeps moving smoothly. But when an obstacle comes within a certain distance, the sensor immediately detects it. The robot then stops to prevent collision. This ensures safe navigation and collision prevention.
After stopping, the servo motor rotates the sensor to the left and right. The robot compares which side has more open space. Based on this real-time data processing, it makes a decision and turns toward the safer direction. This ability to change direction according to the surroundings is called adaptive navigation.
All of this happens very quickly, within seconds, making the robot appear as if it is thinking before moving.
🔄 In simple terms, the robot follows an intelligent cycle:
1 Move forward
2 Continuously check surroundings
3 Stop when an obstacle is detected
4 Scan left and right
5 Choose the clearer path
6 Move safely again
This is how the robot operates independently while maintaining sensor accuracy, quick decision-making, and reliable movement in a changing environment.
